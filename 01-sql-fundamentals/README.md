# SQL Fundamentals

This section demonstrates the practical application of SQL concepts using MySQL, with a focus on querying, filtering, sorting, data transformation, and aggregate analysis.

## Topics Covered

- SQL database creation and table management
- Data insertion and retrieval
- SELECT statements and column aliases
- Filtering with WHERE and comparison operators
- Multiple conditions using AND
- Range filtering with BETWEEN
- Filtering with IN and LIKE
- Handling missing values using NULL and NOT NULL
- Retrieving unique records using DISTINCT
- Sorting with ORDER BY
- Limiting query results with LIMIT
- Data transformation using CONCAT and calculated columns
- Aggregate functions: COUNT, AVG, MAX, MIN, and SUM
- Grouping records using GROUP BY
- Filtering grouped results using HAVING

## Practical Project

### Employee Records and Salary Analysis

**File:** `01-select-filter-sort.sql`

This project uses a sample business employee dataset to demonstrate SQL querying and analysis.

Practical exercises include:

- Creating a database and employees table.
- Inserting and retrieving employee records.
- Filtering employees by department, employment status, and salary.
- Identifying missing department information.
- Sorting employees by salary and department.
- Calculating annual salaries.
- Analyzing overall salary statistics.
- Comparing employee counts and payroll across departments.
- Filtering departmental salary averages.

## Database Environment

- **Database Management System:** MySQL
- **Development Tool:** MySQL Workbench
- **Dataset:** 10 sample employee records

## Execution and Verification

The SQL script was executed and tested in MySQL Workbench.

The dataset and aggregate calculations were verified, including employee count, average salary, highest salary, lowest salary, and total monthly payroll.
